# edgepad 0.3.0

- **Firmware palm rejection:** palm contacts reported by the touchpad no longer trigger edge gestures or slider actions, reducing accidental actions while typing. Enabled by default; set `palm_rejection = false` and restart to disable it.
- **Lower daemon memory use:** gesture and slider histories no longer accumulate throughout the daemon’s lifetime.
- **Shutdown:** continuous input can no longer postpone the shutdown timeout indefinitely.
- **Installer:** the user service now reads the correct configuration when `XDG_CONFIG_HOME` is customized.
- **Replay:** reversed capability ranges are rejected with a parsing error instead of crashing raw replay.
- **CLI:** consistent help and argument validation. Invalid arguments now exit with code 2.
- **Diagnostics:** `doctor` now reports a missing or inactive daemon service as a failure.
- **Maintenance:** reorganized the recognizer, proxy, CLI, configuration, diagnostics, and action worker into smaller modules, with additional lifecycle and scheduling tests.
